# 移动设备选择退出关键词覆盖警告

>[!IMPORTANT]
>
>如果您定义自定义选择加入、选择退出、帮助或双重选择加入关键词，它们将覆盖Adobe Journey Optimizer的默认入站关键词。 要使默认设置保持有效，请将其显式添加到自定义关键字旁边。 [了解有关选择退出管理的更多信息](/help/using/mobile/mobile-opt-out.md#sms-native-keywords)
>
